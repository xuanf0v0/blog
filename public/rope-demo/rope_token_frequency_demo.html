随 Token 位置变化：频率不变，角度递增

蓝线表示未取模的角度 φ = pω，因此会持续上升；橙色虚线标出每转一圈的 2π、4π……。旋转方向由角度对 2π 取模后的结果决定。

把“转一圈”说准确

旋转角度： φp = pω　　一圈对应的位置间隔： T = 2π / ω

最重要的结论：固定同一对维度时，ω 不会因为 Token 位置 p 增加而改变；每向后移动一个位置，角度固定增加 ω。频率越高，单位位置转得越多，完成一整圈所需的位置间隔就越少。
