# LeetGPU 样稿重构设计

## 目标

将 `src/content/posts/leetgpu-vector-addition.md` 重构为可复现的 CUDA 解题教程。文章应帮助已经掌握 C++ 基础的读者理解一维 CUDA 索引、kernel launch 与向量化优化的边界，而不是复述题解或堆叠代码版本。

## 范围

本次仅修改样稿正文；保留现有 frontmatter、题目链接、基础 CUDA 实现和 `float4` 优化实现。后续 23 篇文章是否采用同一模板，取决于样稿审阅结果。

## 文章结构

1. 标题后添加 TL;DR，明确基础实现、核心索引关系和优化结论。
2. 添加「适用读者与前置知识」，说明读者需要了解 C++、CUDA 的 grid/block/thread 基础概念。
3. 用「问题与数据布局」说明 `C[i] = A[i] + B[i]` 与独立元素并行的关系。
4. 用「基础实现」展示最小可工作的 kernel 和 launch 配置，并解释边界保护。
5. 用「索引与 launch 推导」集中解释全局索引、向上取整和最后一个 block 的空闲线程，删除各版本中重复的解释。
6. 用「优化版本：float4」展示向量化版本，明确 16 字节对齐、尾部元素处理和收益受访存模式、硬件与输入规模影响，不能声明未经测量的性能结果。
7. 用「常见错误」和「小结」收束，保留实际可操作的检查项。

## 写作约束

- 使用自然中文，遵守中英文、数字与单位的间距约定。
- 保留 CUDA、GPU、kernel、grid、block、thread、float4 等通用术语与代码标识符。
- 删除「先不要急着优化」「参考文里反复提到」等元叙述和重复套话。
- 所有代码围栏标注 `cpp`，不改变现有代码的行为或宣称其已在新的环境中验证。
- 不添加虚构基准、外部来源、截图或链接。

## 验收标准

- frontmatter 和 `sourceLink` 不变。
- 正文只有一处基础索引推导，且结构按上述章节顺序组织。
- 保留基础实现与 `float4` 优化示例，并准确写明优化的限制条件。
- Markdown 标题层级连续，代码围栏完整，构建可解析该文章。
